1.1. Как е организиран кодът?

Важно е да разбереш, че кодът, който си изпратил, не съдържа абсолютно цялата логика на приложението.

Той използва друг Python файл – models.py, от който взема класа BookCatalog.

Можем да си представим проекта така:

BookCatalog Project

Кодът, който разглеждаме сега, е main.py. Показва менюто и комуникира с потребителя.

models.py

Съдържа класа BookCatalog и логиката за добавяне, търсене, сортиране и премахване на книги.

books.json

Файлът, в който се съхраняват книгите.

main.py използва models.py, а той работи с books.json.

Това разделение е полезно, защото не е необходимо целият код да бъде написан на едно място.

main.py се занимава основно с комуникацията с потребителя, а models.py – с обработката на информацията.


2. Първи редове – импортиране на библиотеки

Нека започнем с първите редове:

    """Конзолно меню за каталога на книги."""

    import sys
    from pathlib import Path

    from models import BookCatalog


2.1. Какво е import?

В Python import означава, че искаме да използваме функционалност, която вече е написана някъде другаде.

Представи си, че имаш кутия с инструменти. Вместо да произвеждаш всеки инструмент сам, вземаш готовия, когато ти потрябва.

Точно това прави import.


2.2. Какво е sys?

    import sys

sys е стандартна библиотека на Python.

Тя предоставя различни функции и информация, свързани с работата на самия Python интерпретатор и програмата.

В нашия случай ще използваме:

    sys.stdout
    sys.stdin

Това са два специални потока:

- stdout – стандартният изход. Обикновено това е конзолата, в която програмата показва текст.
- stdin – стандартният вход. Обикновено това е клавиатурата, от която потребителят въвежда информация.

Например:

    print("Здравей")

Използва стандартния изход, за да покаже текста.

А:

    name = input("Име: ")

Използва стандартния вход, за да получи информация от потребителя.


2.3. Какво е pathlib?

    from pathlib import Path

Тук имаме малко по-различен синтаксис.

from означава, че искаме да вземем нещо конкретно от даден модул.

В случая:

- pathlib е модул за работа с файлови пътища.
- Path е клас от този модул.

Какво е файлов път?

Например:

    C:\Users\Nasko\Documents\books.json

Това е пътят до даден файл на компютъра.

Path ни помага да работим с такива пътища по удобен начин.


2.4. Какво е BookCatalog?

    from models import BookCatalog

Това е най-интересният import в нашия случай.

Тук вземаме класа BookCatalog от файла models.py.

Вероятно в него има нещо подобно:

    class BookCatalog:
        ...

Ще разгледаме какво представлява един клас малко по-надолу.

За момента запомни:

BookCatalog е готова структура, която съдържа логиката за управление на книгите.

Вместо да пишем цялата логика в main.py, използваме вече създадения клас.


3. Променливата DATA_FILE

Следващият ред:

    DATA_FILE = Path(__file__).with_name("books.json")

Това е много интересен ред, защото съчетава няколко концепции.

Първо трябва да разберем какво е променлива.


3.1. Какво е променлива?

Променливата е място, в което съхраняваме някаква информация.

Например:

    name = "Atanas"
    age = 25
    price = 19.99

Тук имаме три променливи:

Променлива    Стойност    Тип информация
name          "Atanas"    Текст
age           25          Цяло число
price         19.99       Десетично число

Символът = означава присвояване.

Тоест:

    age = 25

означава: запази стойността 25 в променливата age.

Важно: = в Python не означава математическо равенство. За сравнение на две стойности използваме ==.


3.2. Какво представлява DATA_FILE?

    DATA_FILE = Path(__file__).with_name("books.json")

Тук създаваме променлива, която съдържа пътя до файла books.json.

Нека разгледаме израза отляво надясно.

Първо:

    __file__

Това е специална Python променлива, която съдържа пътя до файла, в който се намира текущият код.

Например:

    C:\Projects\BookCatalog\main.py

Второ:

    Path(__file__)

Превръщаме този текст в обект от тип Path, с който можем да извършваме операции с файлови пътища.

Трето:

    .with_name("books.json")

Казваме: използвай същата директория, но замени името на файла с books.json.

Ако main.py се намира тук:

    C:\Projects\BookCatalog\main.py

резултатът ще бъде:

    C:\Projects\BookCatalog\books.json

Накрая този резултат се записва в DATA_FILE.

Защо името е с главни букви?

В Python съществува конвенция, според която променливи, които не трябва да се променят по време на изпълнението на програмата, често се изписват с главни букви.

Това не ги прави автоматично константи. Просто е начин програмистът да покаже, че стойността е предназначена да остане постоянна.


4. Какво представлява функцията?

Сега стигаме до една от най-важните концепции в програмирането.

    def configure_console():

Това е дефиниране на функция.


4.1. Какво е функция?

Функцията е блок от код, който изпълнява определена задача.

Представи си, че имаш пералня.

Вместо всеки път да обясняваш на пералнята всички стъпки за изпиране, избираш програма „Памук 40 градуса“.

Тази програма представлява предварително дефинирана последователност от действия.

Функциите работят по подобен начин.

Например:

    def say_hello():
        print("Здравей!")

Тук създадохме функция с име say_hello.

Но има нещо много важно!

Самото създаване на функцията не означава, че тя ще бъде изпълнена.

За да я изпълним, трябва да я извикаме:

    say_hello()

Резултат:

    Здравей!


4.2. Какво означава def?

def е ключова дума в Python, която се използва за дефиниране на функции.

Общият синтаксис е:

    def име_на_функцията():
        код

- def – създаваме функция.
- име_на_функцията – избираме нейното име.
- () – тук могат да се подават допълнителни данни.
- : – показва, че следва тялото на функцията.
- Отстъпът (indentation) – показва кои редове принадлежат към функцията.


4.3. Какво е indentation?

В Python отстъпите са изключително важни.

Например:

    def say_hello():
        print("Здравей!")
        print("Как си?")

    print("Край")

Двата реда с отстъп принадлежат на функцията.

Последният ред не принадлежи на функцията.

Ако извикаме say_hello(), ще получим:

    Здравей!
    Как си?

Ако не я извикаме, нищо от тези два реда няма да се изпълни.


5. Функцията configure_console()

Нека разгледаме първата реална функция от програмата:

    def configure_console():
        """Настройва конзолата за български текст, когато платформата го позволява."""
        for stream in (sys.stdout, sys.stdin):
            reconfigure = getattr(stream, "reconfigure", None)
            if reconfigure is None:
                continue
            try:
                reconfigure(encoding="utf-8")
            except (AttributeError, OSError, ValueError):
                continue

Тази функция настройва входа и изхода на конзолата, за да може правилно да работи с UTF-8 кодиране.

Това е важно заради кирилицата.

Например искаме да можем да показваме:

    Здравей! Каталог на книги.

без символите да се визуализират неправилно.

Но тук има няколко нови концепции.


5.1. Какво е for?

    for stream in (sys.stdout, sys.stdin):

for е цикъл.

Цикълът позволява да изпълняваме определен код многократно.

Например:

    for number in (1, 2, 3):
        print(number)

Резултатът ще бъде:

    1
    2
    3

Какво се случва?

1. Python взема първата стойност – 1.
2. Записва я в променливата number.
3. Изпълнява print(number).
4. Взема следващата стойност – 2.
5. Изпълнява отново кода.
6. Продължава, докато свършат стойностите.

В нашия случай:

    (sys.stdout, sys.stdin)

Това е кортеж (tuple) – структура, която съдържа няколко стойности.

Следователно цикълът ще се изпълни два пъти:

- Първо със sys.stdout.
- След това със sys.stdin.

Променливата stream последователно ще съдържа тези две стойности.


5.2. Какво е getattr()?

    reconfigure = getattr(stream, "reconfigure", None)

Тук използваме вградена функция на Python – getattr().

Тя ни позволява да вземем определен атрибут от даден обект.

Например:

    class Person:
        name = "Atanas"

    person = Person()
    print(getattr(person, "name"))

Резултат:

    Atanas

Какво прави getattr()?

Тя получава два основни аргумента:

    getattr(обект, "име_на_атрибут")

В нашия случай:

    getattr(stream, "reconfigure", None)

Означава:

Провери дали обектът stream има атрибут с име reconfigure.

Ако има – върни го.

Ако няма – върни None.

None е специална стойност в Python, която означава липса на стойност.

Резултатът се записва в променливата reconfigure.


5.3. Какво е if?

    if reconfigure is None:
        continue

if означава „ако“.

С него проверяваме дали дадено условие е изпълнено.

Пример:

    age = 20
    if age >= 18:
        print("Пълнолетен")

Тъй като age е 20, условието е вярно и се изпълнява print().

В нашия код проверяваме:

    reconfigure is None

Това означава: дали reconfigure няма стойност?

Тук се срещаме с is.

is проверява дали две стойности са един и същ обект. За проверка дали нещо е None, стандартният Python подход е именно:

    if variable is None:

Ако условието е вярно, изпълняваме:

    continue


5.4. Какво прави continue?

continue се използва в цикли.

То означава:

Пропусни останалата част от текущото завъртане на цикъла и премини към следващото.

Например:

    for number in (1, 2, 3, 4, 5):
        if number == 3:
            continue
        print(number)

Резултат:

    1
    2
    4
    5

Когато Python стигне до числото 3, условието е вярно и continue пропуска print().

В нашия код това означава, че ако конзолният поток няма метод reconfigure, просто преминаваме към следващия поток.


5.5. Какво е try и except?

    try:
        reconfigure(encoding="utf-8")
    except (AttributeError, OSError, ValueError):
        continue

Това е механизъм за обработка на грешки.

Представи си, че програмата се опитва да отвори файл, но той не съществува.

Без обработка на грешки програмата може да прекрати работата си.

С try и except можем да кажем:

„Опитай да изпълниш този код. Ако възникне определена грешка, направи нещо друго.“

Пример:

    try:
        number = int(input("Въведи число: "))
        print(number)
    except ValueError:
        print("Това не е валидно число!")

Ако потребителят въведе abc, Python няма да може да го превърне в цяло число и ще възникне ValueError.

Тогава ще се изпълни кодът в except.

В нашия случай:

    reconfigure(encoding="utf-8")

се опитва да настрои кодирането на конзолата.

Ако възникне една от трите посочени грешки:

- AttributeError
- OSError
- ValueError

програмата няма да спре, а ще продължи към следващия поток.

Обърни внимание: try и except не са задължителни при всяка функция. Използват се, когато искаме да обработим възможни проблеми.


6. Функцията load_examples()

    def load_examples(catalog):
        """Добавя няколко книги, за да може каталогът да се разгледа веднага."""
        examples = [
            ("1984", "Джордж Оруел", 1949),
            ("Майстора и Маргарита", "Михаил Булгаков", 1967),
            ("Под игото", "Иван Вазов", 1894),
            ("Хари Потър и Философският камък", "Дж. К. Роулинг", 1997),
        ]
        for title, author, year in examples:
            catalog.add_book(title, author, year)

Тази функция добавя предварително зададени книги в каталога.

Но тук има две много важни концепции:

1. Аргументи на функции.
2. Списъци и кортежи.


6.1. Какво представлява catalog в скобите?

    def load_examples(catalog):

До момента разглеждахме функции без параметри:

    def say_hello():

Но можем да подаваме информация на функциите.

Например:

    def say_hello(name):
        print("Здравей, " + name)

Когато извикаме:

    say_hello("Atanas")

ще получим:

    Здравей, Atanas

Тук name е параметър.

А "Atanas" е аргументът, който подаваме при извикването.

В нашия случай:

    def load_examples(catalog):

означава, че функцията очаква да получи един аргумент, който ще бъде достъпен вътре под името catalog.

Този аргумент е обект от класа BookCatalog.

Ще разгледаме подробно обектите след малко.


6.2. Какво е списък (list)?

    examples = [
        ("1984", "Джордж Оруел", 1949),
        ("Майстора и Маргарита", "Михаил Булгаков", 1967),
        ("Под игото", "Иван Вазов", 1894),
        ("Хари Потър и Философският камък", "Дж. К. Роулинг", 1997),
    ]

Списъкът е структура, която позволява да съхраняваме множество стойности в една променлива.

Пример:

    numbers = [1, 2, 3, 4, 5]

Вместо да създаваме пет отделни променливи, съхраняваме всички числа в един списък.

В нашия случай списъкът examples съдържа четири елемента.

Всеки елемент представлява кортеж с три стойности:

    ("1984", "Джордж Оруел", 1949)

Това са:

- Заглавие.
- Автор.
- Година.

Какво е tuple (кортеж)?

Кортежът прилича на списък, но обикновено се използва за групиране на стойности, които принадлежат заедно.

Разликата е, че списъкът може да бъде променян, докато кортежът е неизменяем.

Пример:

    book = ("1984", "Джордж Оруел", 1949)

Тук имаме един кортеж с три елемента.


6.3. Как работи този цикъл?

    for title, author, year in examples:
        catalog.add_book(title, author, year)

Това е много важен момент.

Вече знаем какво прави for, но тук имаме нещо допълнително:

    title, author, year

Python разопакова кортежа и разпределя стойностите по отделните променливи.

Да разгледаме първото завъртане:

    ("1984", "Джордж Оруел", 1949)

Python автоматично прави следното:

    title = "1984"
    author = "Джордж Оруел"
    year = 1949

След това изпълнява:

    catalog.add_book(title, author, year)

Тоест извиква метода add_book() на обекта catalog и подава трите стойности.

При следващото завъртане ще получи информацията за „Майстора и Маргарита“.

Така четирите книги се добавят една след друга.


6.4. Какво е метод?

Тук за първи път виждаме нещо много важно:

    catalog.add_book(...)

Това се нарича извикване на метод.

Методът е функция, която принадлежи на даден обект или клас.

Разликата между функция и метод е най-вече в това, че методът е свързан с определен обект.

Например:

    print("Здравей")

print() е функция.

А:

    catalog.add_book(...)

add_book() е метод на обекта catalog.

    def print_menu():

Това е една от най-лесните функции.

Тя просто показва менюто.


7.1. Какво е print()?

print() е вградена функция на Python, която показва информация на екрана.

Например:

    print("Hello")

Резултат:

    Hello

Можем да показваме и числа:

    print(10)

Резултат:

    10

А можем и да комбинираме текст и числа:

    age = 25
    print("Възраст:", age)

Резултат:

    Възраст: 25

В нашия случай:

    print()

е празен print, който просто създава нов ред.

След това останалите print() извеждат отделните редове на менюто.


8. Функцията show_books()

    def show_books(catalog, books):
        print()
        print(catalog.format_table(books))

Тази функция показва книги на екрана.

Забележи, че приема два аргумента:

    catalog
    books

Това означава, че когато я извикаме, трябва да ѝ подадем две неща.

Например:

    show_books(catalog, catalog.list_books())

Какво се случва?

- Първият аргумент е обектът catalog.
- Вторият аргумент е резултатът от метода catalog.list_books().

Методът list_books() вероятно връща списък с всички книги.

След това:

    catalog.format_table(books)

извиква друг метод, който превръща информацията в таблица за показване.

Например резултатът може да изглежда така:

    Заглавие                     Автор             Година
    -----------------------------------------------------
    1984                         Джордж Оруел      1949
    Под игото                    Иван Вазов        1894

Тук трябва да запомниш една нова дума:

return – връщане на резултат от функция.

Например:

    def add_numbers(a, b):
        result = a + b
        return result

Когато напишем:

    answer = add_numbers(5, 3)

функцията връща числото 8, което се записва в answer.

Вероятно методът format_table() работи по подобен начин – създава текст и го връща.


9. Функцията add_book()

    def add_book(catalog):
        title = input("Заглавие: ")
        author = input("Автор: ")
        year = input("Година: ")
        try:
            catalog.add_book(title, author, year)
        except ValueError as error:
            print(error)
            return
        print("Книгата е добавена и записана.")

Тази функция позволява на потребителя да добави книга.

В нашия случай комбинацията:

14.2. Създаване на обект

Това е един от най-важните редове в целия проект.

Тук се срещаме с понятията:

- Обект (object).
- Конструктор.

Какво е клас?

Класът е шаблон, по който създаваме обекти.

Представи си, че имаш чертеж на автомобил.

Чертежът описва как трябва да изглежда автомобилът и какви характеристики трябва да има.

Но самият чертеж не е автомобил.

Класът е като този чертеж.

Обектът е реалният автомобил, създаден по него.

В нашия проект:

    BookCatalog

е класът.

А:

    catalog

е обектът, който създаваме от този клас.

Можем да създадем и два различни обекта от един клас:

    catalog1 = BookCatalog(DATA_FILE)

Това са два отделни обекта, създадени по един и същ шаблон.

Това създава нов обект от класа BookCatalog.

Подаваме му DATA_FILE, за да знае с кой файл да работи.

Вероятно в models.py има нещо подобно:

    class BookCatalog:
        def __init__(self, file_path):
            self.file_path = file_path
            self.books = []

Тук виждаме още няколко важни неща:

- class – създава клас.
- __init__ – специален метод, който се изпълнява при създаването на обекта.
- self – препратка към текущия обект.
- self.books – информация, която принадлежи на обекта.

Не е необходимо да разбираш напълно self и __init__ още сега. Важно е да запомниш, че класът определя какво може да прави обектът, а обектът съдържа конкретните данни.

17. Основният цикъл на програмата – while

Сега стигаме до една от най-важните части:

Това е основният цикъл на менюто.


17.1. Какво е while?

while означава „докато“.

Той изпълнява даден блок от код, докато определено условие е вярно.

Пример:

    number = 1
    while number <= 5:
        print(number)
        number = number + 1

Резултат:

    1
    2
    3
    4
    5

Какво се случва?

1. Проверява дали number <= 5.
2. Ако е вярно, показва числото.
3. Увеличава го с 1.
4. Връща се обратно и проверява условието.
5. Когато числото стане 6, условието вече не е вярно и цикълът приключва.


17.2. Какво означава while True?

Тук условието винаги е вярно.

17.3. Как работи цикълът в нашия проект?

    while True:
        print_menu()
        choice = input("Избор: ").strip()

При всяко завъртане:

1. Показва менюто.
2. Изчаква потребителят да въведе избор.
3. Записва избора в choice.
4. Проверява какво е избрал потребителят.
5. Изпълнява съответната функция.
6. Връща се в началото на цикъла.
7. Отново показва менюто.

Това позволява програмата да продължава да работи, докато потребителят не избере изход.


18. Как се обработват изборите от менюто?

    if choice == "1":
        add_book(catalog)
    elif choice == "2":
        show_books(catalog, catalog.list_books())
    elif choice == "3":
        filter_books(catalog)
    elif choice == "4":
        sort_books(catalog)
    elif choice == "5":
        search_books(catalog)
    elif choice == "6":
        remove_book(catalog)
    elif choice == "0":
        print("Довиждане.")
        break
    else:
        print("Невалиден избор. Въведете число от менюто.")

Това е логиката, която управлява менюто.

Забележи, че тук сравняваме choice с текст:

    choice == "1"

а не с число:

    choice == 1

Защо?

Защото input() връща текст, а не число.

Следователно, ако потребителят въведе 1, променливата choice ще съдържа "1".

Ето какво се случва при различните избори:

Въведено    Какво се изпълнява
"1"         add_book(catalog)
"2"         show_books(...)
"3"         filter_books(catalog)
"4"         sort_books(catalog)
"5"         search_books(catalog)
"6"         remove_book(catalog)
"0"         Прекратяване на програмата

Какво прави break?

    elif choice == "0":
        print("Довиждане.")
        break

break прекратява цикъла, в който се намира.

Тъй като сме в while True, когато потребителят въведе "0", цикълът приключва и програмата продължава след него.

Ако потребителят въведе нещо различно от изброените стойности, се изпълнява:

    else:
        print("Невалиден избор. Въведете число от менюто.")

Това е защита срещу неправилен избор.


19. Последните два реда – откъде започва изпълнението?

    if __name__ == "__main__":
        main()

Това е много важен Python механизъм.

Нека първо разберем какво е:

    __name__

Това е специална променлива, която Python създава автоматично.

Тя показва по какъв начин се използва текущият Python файл.

Има две основни ситуации:

Ситуация 1: Стартираш директно main.py.

Тогава:

    __name__ == "__main__"

е вярно.

Следователно се изпълнява:

    main()

Това стартира цялата програма.

Ситуация 2: Друг Python файл импортира main.py.

Например:

    import main

Тогава __name__ няма да бъде "__main__", а "main".

Следователно функцията main() няма да бъде изпълнена автоматично.

Защо това е полезно?

Позволява един Python файл да бъде използван като модул в друг проект, без автоматично да стартира цялото приложение.

Това е стандартна практика в Python.


20. Как протича цялата програма от начало до край?

Нека съберем всичко, което научихме.

Последователност на изпълнение

1. Стартиране на main.py
   Python прочита кода и дефинира функциите.

2. Проверка на __name__
   Ако файлът е стартиран директно, се извиква main().

3. Настройване на конзолата
   Изпълнява се configure_console().

4. Създаване на каталог
